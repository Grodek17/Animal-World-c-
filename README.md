# Animal World – C++

A simple turn-based animal world simulation developed in C++ using the curses library as part of a university Object-Oriented Programming course.

The project explores basic OOP principles through interactions between organisms in a two-dimensional world.

## Features

- Object-oriented structure with inheritance and polymorphism
- Animal movement and collision handling
- Basic reproduction mechanics
- Turn-based simulation with terminal visualization
- Different animal species with individual behaviors

## Technologies

- C++
- curses / ncurses
- Object-Oriented Programming (OOP)

## Project Status

This repository contains an early, unfinished implementation of the Animal World simulation.

Development continued in Java as a separate, more complete project with a graphical interface and additional gameplay mechanics.

The original C++ implementation has been preserved as a record of my early experience with object-oriented programming.
